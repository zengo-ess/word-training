# Приложение для изучения английских слов — дизайн

**Дата:** 2026-06-04
**Статус:** черновик к согласованию

## Общее описание

Веб-приложение для изучения английских слов через карточки с картинками.
Вдохновлено словарным тренажёром LinguaLeo. Mobile-first, работает в браузере,
данные хранятся на бэкенде. Проект персональный (один пользователь).

## Стек

- **Frontend:** Vite + React + TypeScript (mobile-first)
- **Backend:** Node.js + Express + TypeScript
- **БД:** SQLite через `better-sqlite3` (синхронный API)
- **Деплой:** Docker Compose на VPS
- **UI:** свой минималистичный mobile-first CSS, иконки `lucide-react`
  (без тяжёлой компонентной библиотеки — экранов немного, нужен полный
  контроль над карточками и упражнениями)

### Внешние интеграции

| Интеграция | Назначение | Где используется |
|------------|-----------|------------------|
| **MyMemory API** | перевод EN→RU при добавлении слова | рантайм, без ключа |
| **Unsplash API** | картинки для карточек (поиск + ручная замена) | рантайм, нужен ключ |
| **Google Text-to-Speech API** | озвучка слов — генерация MP3 один раз при добавлении слова | рантайм, нужен ключ |
| **Anthropic API** | генерация данных встроенных колод | **только локальный разовый скрипт**, НЕ на проде |

## Структура проекта

```
/client                 # Vite + React + TS
/server                 # Node.js + Express + TS
  /db                   # SQLite + миграции (.sql, прогон на старте)
  /routes               # API endpoints
  /services             # MyMemory, Unsplash, Google TTS, spaced repetition
  /uploads/audio        # сгенерированные MP3 ({word_id}.mp3), раздаются статикой
/scripts                # разовый генератор встроенных колод (использует Anthropic)
/data                   # JSON со встроенными колодами
docker-compose.yml
```

Монорепо: `client/` и `server/` каждый со своим `package.json`, общий
`docker-compose.yml` в корне.

## Авторизация

Один пользователь, вход по **одному паролю** (`APP_PASSWORD` в env). На входе
сервер выдаёт JWT для сессии. Таблица `users`, email и хеш пароля **не нужны** —
данные глобальные.

## Модели данных

```
decks
  id, name, is_builtin (встроенные = только чтение), created_at

words
  id, deck_id, english, russian, transcription, example_sentence,
  image_url, audio_url, created_at

progress
  id, word_id,
  -- этап изучения новых слов:
  current_type        (1..5; null если слово уже в SR),
  learned_at          (когда прошло все 5 типов; null если ещё нет),
  -- spaced repetition (SM-2):
  ease_factor (1.3..2.5), interval_days, next_review_at,
  total_reviews, correct_reviews
```

Без `user_id` (один пользователь). Таблица `users` отсутствует.

## Колоды

**Встроенные** (только чтение, данные заранее в JSON):
- Топ 100 глаголов
- Топ 100 существительных
- Топ 100 прилагательных
- Топ 200 самых частых слов (Oxford 3000)
- Тематические: еда, путешествия, работа, эмоции, числа и время

**Пользовательские:**
- Создать свою колоду
- Добавить слово вручную
- Скопировать слово из встроенной колоды к себе

## Добавление слова

Пользователь вводит английское слово → автоматически:
1. **MyMemory** генерирует перевод на русский → подставляется в форму как черновик
2. **Unsplash** подтягивает релевантную картинку (можно заменить вручную, поиск по Unsplash)
3. **Google TTS** генерирует MP3-озвучку слова (см. раздел «Аудио для карточек»)
4. Пользователь правит при необходимости → сохранить

**Для пользовательских слов транскрипция и пример предложения НЕ подтягиваются**
(остаются пустыми). Следствия:
- Транскрипция в карточках просто не отображается, если пустая.
- **Тип 3 (вставить пропуск)** для слова без `example_sentence` **пропускается**.

У встроенных слов транскрипция и примеры есть (сгенерированы заранее разовым скриптом).

## Аудио для карточек

- **Сервис:** Google Text-to-Speech API.
- **Формат:** MP3, 32 kbps (~2–4 КБ на слово).
- **Генерация:** один раз при добавлении слова; файл сохраняется на VPS.
- **Хранение:** файл в `/uploads/audio/{word_id}.mp3`, путь записывается в `words.audio_url`.
- Раздаётся бэкендом как статика (например, `GET /uploads/audio/{word_id}.mp3`).

Логика в сервисе создания слова:
1. Получили слово.
2. Дёрнули Google TTS → получили MP3.
3. Сохранили файл в `/uploads/audio/{word_id}.mp3`.
4. Записали путь в `audio_url`.

Если генерация не удалась (нет ключа / ошибка API) — `audio_url` остаётся пустым,
слово сохраняется без озвучки (фронт прячет кнопку 🔊). Встроенные слова получают
аудио из разового скрипта генерации колод.

Использование на фронте:
- На карточке кнопка 🔊 — воспроизводит файл по `audio_url`.
- В упражнении «Аудио» (Тип 5) — файл автоматически проигрывается при показе карточки.

## Словарный тренажёр

Пять типов упражнений:

| Тип | Название | Что показываем | Ответ |
|-----|----------|----------------|-------|
| 1 | Перевод EN→RU | картинка + англ. слово + транскрипция | выбрать перевод из 4 |
| 2 | Перевод RU→EN | русское слово | выбрать англ. из 4 |
| 3 | Вставить пропуск | пример предложения с пропуском | вписать слово руками |
| 4 | Собрать из букв | перемешанные буквы слова | расставить по порядку (drag & drop / клик) |
| 5 | Аудио | произношение (MP3 из `audio_url`, автоплей) | выбрать перевод из 4 |

### Логика прохождения новых слов

Батч = **до 20 слов** (если доступно меньше — берём сколько есть).
Идём **по слоям типов** (как в LinguaLeo), внутри слоя — очередь с накоплением ошибок:

```
для типа T от 1 до 5:
    очередь = слова батча (по порядку)
    ошибочные = []
    пока очередь не пуста:
        берём слово из начала очереди
        показываем упражнение типа T
        верно   → слово прошло тип T
        неверно → кладём слово в "ошибочные"   (остаёмся на T)
        если очередь опустела, но есть ошибочные:
            перемешиваем ошибочные → это новая очередь
            ошибочные = []
    # все слова прошли тип T → переходим к T+1

после типа 5 → все слова батча выучены → уходят в spaced repetition
```

Ключевые правила:
- Сначала **все** слова проходят Тип 1, потом все — Тип 2, и т.д. (однотипные задания группой).
- Ошибка **не сбрасывает на Тип 1** — слово остаётся на текущем типе и копится в «ошибочных».
- Когда основная очередь опустела, ошибочные перемешиваются и показываются снова — до нуля.
- Слово «выучено» = прошло все 5 типов (повторы при ошибках разрешены).
- Если у слова нет примера → Тип 3 для него пропускается.

## Spaced repetition (SM-2)

После первого полного прохождения слово получает расписание повторений:
- 1-й повтор: через 1 день
- 2-й повтор: через 3 дня
- 3-й повтор: через 7 дней
- Далее: интервал × `ease_factor` (1.3..2.5)

**Режим повторения** (когда подошёл срок) — упрощённый, только Тип 1 / Тип 2,
выбор по настройке направлений:
- **EN→RU** → только Тип 1
- **RU→EN** → только Тип 2
- **оба** → чередуем Тип 1 и Тип 2 от слова к слову

Ответ верный → интервал растёт по SM-2. Ошибся → интервал сбрасывается
(слово снова с коротким интервалом).

## Направления

Настройка в тренажёре: EN→RU / RU→EN / оба. Влияет **только на режим повторений**
(в новых словах все 5 типов фиксированы и уже включают оба направления).

## Статистика

- Сколько слов изучено / в процессе / запланировано на сегодня
- Стрик (количество дней подряд с занятиями)
- Прогресс по каждой колоде (% выученных слов)

## API endpoints

```
POST   /api/auth/login              # вход по паролю → JWT

GET    /api/decks                   # все колоды (встроенные + пользовательские)
POST   /api/decks                   # создать свою колоду
GET    /api/decks/:id/words         # слова колоды

POST   /api/words                   # добавить слово (вызывает MyMemory + Unsplash + Google TTS)
PUT    /api/words/:id               # обновить слово
DELETE /api/words/:id

GET    /api/unsplash/search         # поиск картинок для ручной замены

GET    /api/training/today          # слова для тренировки сегодня (новые + повторения)
POST   /api/training/result         # записать результат упражнения

GET    /api/stats                   # статистика пользователя
```

```
APP_PASSWORD=          # пароль входа

```

## Порядок разработки

1. Инициализация (структура папок, Docker Compose, SQLite миграции)
2. Бэкенд: авторизация (вход по паролю → JWT)
3. Бэкенд: колоды и слова, интеграция MyMemory + Unsplash
4. Бэкенд: тренажёр (логика слоёв) и spaced repetition (SM-2)
5. Фронтенд: экран колод и добавление слова
6. Фронтенд: 5 типов упражнений + логика прохождения батча
7. Фронтенд: повторения, статистика и стрик
8. Разовый скрипт + наполнение встроенных колод (JSON)
9. Деплой на VPS
