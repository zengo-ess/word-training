# Handoff: Тренажёр английских слов (Vocabulary Trainer)

## Overview
Mobile-first веб-приложение для изучения английских слов по карточкам с картинками
(вдохновлено словарным тренажёром LinguaLeo, но с оригинальным дизайном). Персональное,
один пользователь. Этот пакет — **hi-fi дизайн-прототип** всего флоу: дашборд, колоды,
тренажёр новых слов (5 типов упражнений), режим интервального повторения (SM-2),
добавление слова, статистика, профиль.

Бэкенд/стек продукта (из исходного ТЗ): Vite + React + TS (клиент), Node + Express + TS
(сервер), SQLite (better-sqlite3), Docker Compose. Интеграции: MyMemory (перевод),
Unsplash (картинки), Web Speech API (озвучка), Anthropic API (разовый офлайн-генератор
встроенных колод). Подробное продуктовое ТЗ — см. раздел «Логика тренажёра» ниже.

## About the Design Files
Файлы в этом бандле — **дизайн-референсы, сделанные на HTML/React+Babel** (прототип,
показывающий внешний вид и поведение), **а не продакшн-код для копирования**. Задача —
**воспроизвести эти экраны в реальной кодовой базе продукта** (Vite + React + TypeScript)
по её принятым паттернам: вынести дизайн-токены в CSS-переменные / тему, разбить экраны
на компоненты, подключить реальные API (MyMemory, Unsplash, Web Speech) и серверную
логику (spaced repetition, прогресс, колоды). Прототип использует React 18 через Babel-
standalone и инлайновые стили — в продакшене замените на нормальную сборку и систему
стилей (CSS Modules / Tailwind / styled — на ваш выбор по кодовой базе).

Иконки в прототипе — кастомный набор lucide-подобных путей (`app/icons.jsx`). В продукте
ТЗ предполагает `lucide-react` — используйте его. Картинки слов в прототипе — пастельные
плитки с иконкой («плейсхолдер фото»); в продукте сюда подставляются реальные фото
Unsplash (компонент `WordTile` помечает их бейджем «фото»).

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, скругления, тени, анимации и
интерактив. Воспроизводить можно пиксель-в-пиксель. Демонстрационные батчи в прототипе
укорочены до 6 слов для играбельности — в продукте батч **до 20 слов** (см. логику).

### Анимации (важно)
Все entrance-анимации делают **только transform** (translate/scale), без `opacity:0` в
keyframes — чтобы контент был виден на любом кадре (это сознательное решение, не баг).
Уважается `prefers-reduced-motion: reduce` (анимации отключаются).
- `fadeUp` .35s, `exEnter` .3s (translateX 18→0, смена упражнения), `fbEnter` .3s (тост
  фидбэка), `pop` .5s spring (финальные экраны), `tilePop` .18s (буква встаёт в слот),
  `sheetUp` .32s + `bdIn` (нижний шит). Easing: `cubic-bezier(.34,1.56,.64,1)` (spring)
  и `cubic-bezier(.4,0,.2,1)` (smooth).
- Нажатия: `.btn-press:active { transform: scale(.94) }`, карточки `scale(.985)`.

## Interactions & Behavior

- **Навигация:** нижние вкладки переключают основные экраны; деталь колоды / тренажёр /
  повтор / добавление — оверлеи в стеке (есть «назад»); карточка слова — нижний шит.
- **Озвучка:** Web Speech API — `new SpeechSynthesisUtterance(text)`, `lang='en-US'`,
  `rate=0.9`, перед произнесением `speechSynthesis.cancel()`.
- **Drag&drop в Типе 4** в прототипе реализован кликом (tap-to-place / tap-to-remove); в
  продукте можно добавить настоящий drag, поведение сборки/проверки сохранить.
- **Reduced motion:** при `prefers-reduced-motion: reduce` все анимации выключаются.
- **Скейл:** «телефон» масштабируется под вьюпорт (`transform: scale`, вписывается по
  меньшей стороне). В реальном приложении это не нужно — там просто адаптивный мобильный лейаут.

## Логика тренажёра (источник истины — продуктовое ТЗ)

### Прохождение новых слов (батч до 20 слов, по слоям типов)
```
для типа T от 1 до 5:
    очередь = слова батча (по порядку)
    ошибочные = []
    пока очередь не пуста:
        берём слово из начала очереди
        показываем упражнение типа T
        верно   → слово прошло тип T
        неверно → кладём слово в "ошибочные" (остаёмся на T)
        если очередь опустела, но есть ошибочные:
            перемешиваем ошибочные → это новая очередь
            ошибочные = []
    # все слова прошли тип T → переходим к T+1
после типа 5 → все слова батча выучены → уходят в spaced repetition
```
Ключевое: сначала ВСЕ слова проходят Тип 1, затем все Тип 2 и т.д. Ошибка НЕ сбрасывает на
Тип 1 — слово остаётся на текущем типе и копится в «ошибочных». Слово «выучено» = прошло все
5 типов. Если у слова нет `example_sentence` → Тип 3 для него **пропускается** (в прототипе:
`appliesToType(w,3) = !!w.example`; если для типа очередь пуста — слой пропускается целиком).

> Реализация в прототипе — `app/trainer.jsx` (`handleResult`, `enterLayer`, `buildQueue`).

### Spaced repetition (SM-2)
- 1-й повтор через 1 день, 2-й — 3 дня, 3-й — 7 дней, далее интервал × `ease_factor`
  (1.3..2.5). Верный ответ → интервал растёт; ошибка → интервал сбрасывается (короткий).
- Режим повтора упрощён: только Тип 1 / Тип 2 по настройке направления (EN→RU → Тип 1,
  RU→EN → Тип 2, оба → чередование).

### Направления
Настройка EN→RU / RU→EN / оба влияет **только на режим повторений** (в новых словах все 5
типов фиксированы и уже включают оба направления).

### Модели данных (из ТЗ)
`decks(id, name, is_builtin, created_at)` ·
`words(id, deck_id, english, russian, transcription, example_sentence, image_url, created_at)` ·
`progress(id, word_id, current_type 1..5|null, learned_at|null, ease_factor, interval_days,
next_review_at, total_reviews, correct_reviews)`. Без `user_id` (один пользователь, вход по
одному паролю `APP_PASSWORD` → JWT).

### Добавление слова
EN-ввод → MyMemory (перевод-черновик) + Unsplash (картинка, можно заменить поиском) →
правка → сохранить. Для пользовательских слов транскрипция и пример НЕ подтягиваются
(пустые): транскрипция в карточке не показывается, Тип 3 пропускается.

## State Management (что понадобится)
- Текущий экран/вкладка + стек оверлеев; выбранное слово для шита.
- Тема (акцент/тёмная/шрифт/скругления) — в проде это пользовательские настройки/тема.

  target по слою, состояние ответа (idle/correct/wrong), флаг «работа над ошибками».
- Сессия повтора: направление, индекс, массив результатов.
