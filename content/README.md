# Содержимое колод

`decks.json` — снимок всех колод и карточек из локальной SQLite.
Картинки и аудио находятся в `server/uploads` и входят в Git.

Снимок сохраняет идентификаторы колод, карточек и владельцев для последующего переноса.
Учётные записи, пароли и прогресс обучения в него не включены.
Приложение продолжает читать колоды из SQLite. JSON автоматически не импортируется.
